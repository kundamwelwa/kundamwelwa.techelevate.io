Getting Started

To run this project locally or contribute to its development, follow these steps:

Prerequisites





Git installed on your machine.



A GitHub account.



(Optional) Jekyll for local development if the site uses Jekyll.

Installation





Clone the repository:

git clone https://github.com/kundamwelwa/techelevatesite.git
cd techelevatesite



Install dependencies (if using Jekyll):

gem install jekyll bundler
bundle install



Run the site locally:





For a static site, open index.html in a browser.



For a Jekyll site, run:

bundle exec jekyll serve

Then visit http://localhost:4000 in your browser.

Deployment

This site is hosted on GitHub Pages at kundamwelwa.techelevate.io. To deploy updates:





Push changes to the main branch:

git add .
git commit -m "Update site content"
git push origin main



Verify GitHub Pages settings:





Go to the repository’s Settings > Pages.



Ensure the source is set to the main branch and the / (root) folder (or /docs if applicable).



The site will update automatically within a few minutes.
